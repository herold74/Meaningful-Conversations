# Krisen-Hilfsangebote (AT, DE, CH, CA)

**Zuletzt geprüft:** 2026-08-23  
**Laufzeit (Prompts):** `meaningful-conversations-backend/crisisResources.js` → eingebunden in `crisisText.js` (alle Coach-Systemprompts).  
**Prinzip:** Nur **geprüfte, kostenlose** Angebote. Coaches dürfen **keine** weiteren Nummern erfinden. Land/Bundesland kommt aus dem Life-Context-Feld **Land / Bundesland** (EN: Country / State).

Die drei Schritte im Prompt bleiben: **Verifizieren** (Sarkasmus/Tester) → **Region** → **Aktivieren**. Diese Liste ersetzt nur Schritt 3 (keine LLM-halluzinierten Ortsnummern).

**Review:** Jährlich oder wenn eine Nummer als falsch gemeldet wird. AT-Landeszusätze beruhen u. a. auf [gesundheit.gv.at](https://www.gesundheit.gv.at/leben/suizidpraevention/betroffene/krisentelefonnummern.html) (Portal-Stand 30.08.2023); nationale Nummern 2026-08-23 an den Organisationsseiten geprüft.

Land außerhalb AT/DE/CH/CA: [IASP-Verzeichnis](https://www.iasp.info/suicidalthoughts/) nennen, keine Nummern erfinden.

## Prompt-Regeln (kurz)

1. Land aus LC zuordnen; bei Treffer **nur dieses Land**.
2. Land unbekannt: die vier nationalen 24/7-Blöcke (142, DE 0800/116 123, 143, 988) plus passende Notrufe, dann nachfragen.
3. Region unbekannt, Land bekannt: nur nationale Nummern.
4. Zuerst `brand.providerName` (menschlicher Coach), dann Hotlines — das 3-Schritt-Protokoll bleibt.
